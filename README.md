# 🏏 ReelExoApplication

A smooth and engaging cricket reels application built using **ExoPlayer** and **RecyclerView**, inspired by short-form video platforms like Instagram Reels and YouTube Shorts.

This project demonstrates how to create a vertically scrollable video feed where users can seamlessly watch cricket reels with automatic video playback while scrolling.

---

## 🚀 Features

✅ Vertical Reel Scrolling Experience

✅ Auto Play / Pause Videos

✅ High Performance Video Streaming using ExoPlayer

✅ RecyclerView Integration for Infinite Reel Feed

✅ Smooth User Experience

✅ Lightweight and Fast Loading

✅ Modern Android UI

✅ Efficient Memory Management

✅ Beginner-Friendly ExoPlayer Implementation

## ⚙️ How It Works

1. RecyclerView displays reel items vertically.
2. Each item contains a video player.
3. ExoPlayer handles video streaming and playback.
4. As the user scrolls:
   - Current reel starts automatically.
   - Previous reel pauses.
   - Resources are efficiently managed.
